## ติดตั้ง Apps Script (แยกไฟล์)
1. เปิดโปรเจกต์ Apps Script เดิม → ลบ `Code.gs` เดิม
2. กด **+ → Script** สร้างไฟล์ตามชื่อในโฟลเดอร์ `gas/` แล้ววางเนื้อหาแต่ละไฟล์ (ไม่ต้องใส่ .gs ในชื่อ)
3. **Deploy → Manage deployments → Edit → New version → Deploy** (URL เดิมใช้ต่อได้)
4. ครั้งแรกจะขอสิทธิ์ **Google Drive** เพิ่ม (สำหรับเก็บไฟล์หนังสือ) → Allow

## ระบบออกเลขหนังสือ

| ประเภท | รูปแบบเลข (ค่าเริ่มต้น) | ชีต | โฟลเดอร์ |
|---|---|---|---|
| หนังสือภายใน | `มศทท/911` | หนังสือภายใน | `01 หนังสือภายใน/2569/` |
| หนังสือภายนอก | `มศทท.9/951` | หนังสือภายนอก | `02 หนังสือภายนอก/2569/` |
| ประกาศ | `21/2569` | ประกาศ | `03 ประกาศ/2569/` |
| คำสั่ง | `13/2569` | คำสั่ง | `04 คำสั่ง/2569/` |

- เลขรันแยกตามประเภท เริ่มใหม่ทุกปี พ.ศ. ออกเลขที่เซิร์ฟเวอร์ภายใต้ล็อก **ไม่มีเลขซ้ำ** แม้หลายคนกดพร้อมกัน
- ไฟล์ที่แนบถูก **เปลี่ยนชื่อเป็นเลขหนังสือ** อัตโนมัติ เช่น `มศทท.9-951.pdf`, `ประกาศ 21-2569.pdf` (ไฟล์ที่ 2 เป็น `มศทท.9-951 (2).pdf`) — เครื่องหมาย `/` ใช้ในชื่อไฟล์ไม่ได้จึงแทนด้วย `-`
- ทะเบียนเก็บใน Spreadsheet แยก **"ทะเบียนหนังสือ – DLFOffice"** 1 ชีตต่อประเภท (สีแท็บต่างกัน) อยู่ในโฟลเดอร์ Drive ที่กำหนด
- เปลี่ยนรูปแบบเลขได้ที่ Script Properties เช่น `DOC_FORMAT_INTERNAL` = `มศทท/{n}` (`{n}` ลำดับ, `{be}` ปี พ.ศ.)

**สิทธิ์**
| | ผู้ใช้ทั่วไป | ผู้ดูแลระบบ |
|---|---|---|
| ดูทะเบียน / ค้นหา | ✓ | ✓ |
| ออกเลขใหม่ | ✓ | ✓ |
| แนบไฟล์ / แก้รายละเอียด | เฉพาะรายการที่ตนเป็นผู้ขอหรือผู้บันทึก | ✓ ทุกรายการ |
| ยกเลิกเลข / ลบไฟล์ | – | ✓ (เลขที่ยกเลิกจะไม่ถูกนำกลับมาใช้) |
| ลิงก์โฟลเดอร์ Drive / Sheet | – | ✓ |

## นำเข้าทะเบียนเดิม (ทำครั้งเดียว) — ให้เลขรันต่อจากของเดิม
1. อัปโหลด `data/ทะเบียนหนังสือ-ตั้งต้น-2569.xlsx` ไปที่โฟลเดอร์ Drive ของระบบ
2. ดับเบิลคลิกเปิด → **ไฟล์ → บันทึกเป็น Google ชีต**
3. คัดลอก ID จาก URL ของชีตใหม่ (ส่วนระหว่าง `/d/` กับ `/edit`) → ใส่ Script Property **`DOCS_SPREADSHEET_ID`**
4. ใน Apps Script เลือกฟังก์ชัน **`setupDocuments`** → Run → ดู Log ต้องเห็น "ถัดไป มศทท/911, มศทท.9/951, 21/2569, 13/2569"
5. ลบไฟล์ .xlsx ต้นฉบับในโฟลเดอร์ได้

> ไม่นำเข้าก็ได้: ระบบจะสร้างทะเบียนใหม่ให้อัตโนมัติ แล้วตั้งเลขเริ่มด้วย Script Properties
> `DOCSEQ_internal_2569 = 910`, `DOCSEQ_external_2569 = 950`, `DOCSEQ_announce_2569 = 20`, `DOCSEQ_order_2569 = 12`

**สิ่งที่พบในทะเบียนเดิม (เก็บไว้ครบ พร้อมหมายเหตุ)**
- หนังสือภายใน เลข **670–699 ถูกออกซ้ำ 2 รอบ** (ปลาย ก.ค. และต้น ส.ค.) และเลข 448 ซ้ำ → หมายเหตุ "เลขซ้ำในทะเบียนเดิม"
- หนังสือภายนอก เลข 44, 198, 268 ซ้ำ
- เลขที่ถูกใช้แต่ไม่มีชื่อเรื่อง (ภายใน 18, 140, 415, 428, 548, 857, 858 · ภายนอก 227) → ชื่อเรื่อง "(ไม่มีชื่อเรื่องในทะเบียนเดิม)"
- ช่องวันที่ที่ว่างในทะเบียนเดิม ใช้วันที่ของบรรทัดก่อนหน้า
- ชื่อกลุ่มงานถูกปรับให้ตรงกันกับระบบ เช่น "สนับสนุน" → "กลุ่มงานสนับสนุน", "ความร่วมมือฯ" → "กลุ่มความร่วมมือและสื่อสารองค์กร"

## การแชร์ไฟล์
ไฟล์หนังสือใช้สิทธิ์ตามโฟลเดอร์ Drive — ให้แชร์โฟลเดอร์ราก (และ Spreadsheet ทะเบียน) แบบ
**"ทุกคนในองค์กรที่มีลิงก์ดูได้"** หรือแชร์ให้กลุ่มพนักงาน เพื่อให้กดเปิดไฟล์จากระบบได้
